# Objetivo del sitio
Desarrollar y publicar un sitio web empresarial informativo para la empresa Raffastore, dedicada a la comercialización de accesorios para dispositivos móviles. El sitio presenta información sobre la historia, misión, visión y valores de la empresa, además de mostrar el catálogo de productos, facilitar el contacto con los clientes y responder preguntas frecuentes. Fue desarrollado únicamente con tecnologías HTML5 y CSS3, aplicando diseño responsivo para garantizar una correcta visualización en teléfonos móviles, tabletas y computadoras de escritorio.
